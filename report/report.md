# 과제 보고서: 농업 로봇의 엣지 AI와 클라우드 AI 선택

## 1. 선택한 사례
논밭에서 카메라로 작물과 잡초를 구분하여 잡초만 제거하는 제초 로봇

## 2. 판단 결과
**엣지 AI가 적합하다.**

## 3. 기준별 분석

### 속도
- 로봇이 움직이는 중에 영상을 보고 즉시 잡초 위치를 판단해야 한다.
- 엣지 AI는 인터넷을 거치지 않아 응답 지연이 짧다.
- 클라우드 AI는 영상 전송과 결과 수신에 시간이 걸려 판단이 늦어진다.
- 따라서 속도 면에서는 엣지 AI가 유리하다.

### 비용
- 엣지 AI는 로봇에 들어가는 연산 장치 구입비가 초기에 한 번 발생한다.
- 클라우드 AI는 영상을 보낼 때마다 통신비와 서버 사용료가 발생한다.
- 제초 로봇은 넓은 논밭에서 오래 작동하므로 영상 처리량이 많다.
- 사용량이 많을수록 클라우드 비용이 누적되므로, 장기적으로는 엣지 AI가 유리하다.

### 오프라인
- 논밭은 통신 환경이 불안정하거나 인터넷이 아예 되지 않는 곳이 많다.
- 엣지 AI는 인터넷 없이 로봇 안에서 동작한다.
- 클라우드 AI는 연결이 끊기면 로봇이 멈춘다.
- 따라서 오프라인 동작 면에서는 엣지 AI가 유리하다.

### 프라이버시
- 농장 영상에는 개인 정보가 거의 없어 이 기준의 중요도는 높지 않다.
- 그래도 엣지 AI는 영상이 로봇 안에 머물러 외부 유출 위험이 없다.
- 클라우드 AI는 영상을 외부로 전송하는 과정에서 유출 위험이 생긴다.
- 따라서 프라이버시 면에서도 엣지 AI가 유리하지만, 결정적인 근거는 아니다.

### 모델 크기
- 작물과 잡초를 구분하는 일은 비교적 단순한 영상 인식이다.
- 이 정도 작업은 작은 모델로 충분하여 엣지 장치에서도 돌릴 수 있다.
- 큰 모델이 필요한 작업이 아니므로 클라우드를 쓸 이유가 없다.
- 따라서 모델 크기 면에서도 엣지 AI로 충분하다.

## 4. 종합 정리

| 기준 | 유리한 쪽 | 이유 |
|---|---|---|
| 속도 | 엣지 AI | 이동 중 즉시 판단 필요 |
| 비용 | 엣지 AI | 사용량이 많아 클라우드 비용 누적 |
| 오프라인 | 엣지 AI | 논밭은 인터넷이 불안정 |
| 프라이버시 | 엣지 AI | 중요도는 낮으나 유출 위험 없음 |
| 모델 크기 | 엣지 AI | 작은 모델로 충분 |

## 5. 결론
다섯 가지 기준 모두 엣지 AI가 유리하다. 특히 인터넷이 불안정한 논밭에서 즉시 판단해야 한다는 점이 가장 결정적인 근거이다. 따라서 농업 제초 로봇에는 엣지 AI를 적용하는 것이 적합하다.
